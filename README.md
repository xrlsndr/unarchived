PORTFOLIO CHECKLIST

        ADD A NEW SERIES
        [ ] Copy one complete block from SERIES 01 START through SERIES 01 END.
        [ ] Paste it below the last series and update the START/END comment number.
        [ ] Change the h2 title and the section aria-labelledby/id pair.
        [ ] Give the new carousel a unique class name, such as carousel-four.
        [ ] Give every photo input a unique id, such as four-photo-1.
        [ ] Keep each label's for value exactly equal to its checkbox id.
        [ ] Add the new image files inside the images folder.
        [ ] Update each image src to the matching local filename.
        [ ] Update data-context for the text shown under the focused image.
        [ ] Add data-source if you want the local path shown under the focused image.
        [ ] Do not add radio inputs, carousel state labels, or CSS rules.
        [ ] Do not remove the script.js tag at the bottom of this file.

        ADD A PHOTO TO AN EXISTING SERIES
        [ ] Duplicate one complete figure class="photo" inside that series photo-track.
        [ ] Change the checkbox id to the next unique number.
        [ ] Change the label for value to match that new checkbox id.
        [ ] Change the image src to the local file in images.
        [ ] Change data-context and data-source for the new image.
        [ ] Do not edit the arrow buttons, script.js, or styles.css.

        REMOVE A PHOTO
        [ ] Delete the entire matching figure class="photo" block.
        [ ] The JavaScript carousel will recalculate the number of images automatically.

        LOCAL FILE EXAMPLE
        images/UM07.jpg
        data-context="New mural context"
        data-source="images/UM07.jpg"
